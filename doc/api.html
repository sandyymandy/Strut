API reference

The guide pages cover what you need day to day. Every public class and method is in the generated Javadoc.

The Javadoc

The Javadoc is generated from the source when the site is published, so it is always current, and is not stored in the repository. On the published site, the API index opens it.

To read it offline, build it with ./gradlew javadoc and open build/docs/javadoc/index.html. (The link above only works on the published site.)

Where things are

Package (under com.sandymandy.strut)What is in it
StrutClientThe client-side registration entry point: entity, item, armor, blockEntity.
animatableThe interfaces you implement: StrutEntity, StrutItem, StrutBlockEntity, StrutReplacedEntity, and the bone overrides and attachments handles.
animatable.clientRender providers for items and armor.
animationControllers, the animation manager, RawAnimation, PlayState.
animation.authorityThe server-authoritative clock: ServerAnimationStates, AnimationPlayback, AuthorityMode.
animation.overrideBone override properties and scopes.
eventTyped events: StrutEvents, StrutEventType, StrutEventTypes, EventContext, and the clip timelines, bindings and dispatchers beneath it.
modelStrutModel, its conventional variants and the builder.
rendererThe renderers: StrutEntityRenderer, StrutItemRenderer, StrutBlockRenderer, StrutArmorRenderer.
assetsyncAsset sync: StrutAssetSync for servers, and assetsync.client for the client.
utilStrutUtil, Color and other helpers.

Classes and methods marked @ApiStatus.Internal are not part of the API and can change without notice.
