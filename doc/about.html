Where Strut comes from, and its licence.

Origin

Strut is a fork of GeckoLib by Gecko, Eliot, AzureDoom, DerToaster, Tslat and Witixin, and inherits its keyframe animation engine: bone animation, Molang, easings, concurrent animation controllers and sound, particle and event keyframes. Strut adds free-form meshes and armature skinning, a binary model and animation format, server-authoritative animation, typed events, bone overrides and attachments, asset sync, and a GPU render path with shader-pack support.

The GeckoLib wiki still describes some of the inherited behaviour, but its class names and some of its behaviour differ from Strut's. When the two disagree, these pages are right for Strut.

Licence

Strut is released under the MIT License. GeckoLib's own MIT licence notice is retained verbatim in the Strut jar (GECKOLIB_LICENSE), as the licence requires.

About this documentation

These pages are plain HTML with one stylesheet and one small script: no build step, so they open straight from disk and can be published as they are. Every Java sample is a region of a compiled source file, and the build fails if a page and its sample drift apart, so the code you copy is code that compiles against the current API.
